# Logotipos de clientes

Solo logotipos de clientes reales y con autorización para publicarlos.
Formato: SVG (preferido) o PNG transparente, alto ~80 px.
Regístralos en `clientes` dentro de `src/data/contenido.ts`:

    { nombre: 'Nombre del cliente', logo: '/clientes/nombre-cliente.svg' }

Mientras la lista esté vacía, el sitio muestra espacios marcados como pendientes.
